Hello, World! 博客开张

2026年05月21日 #博客 #Hugo

博客正式上线！

经过一番折腾，这个博客终于搭建好了。第一篇 Markdown 文章，聊聊建站这件事。

技术选型

选择 Hugo 的理由很简单：

  • 快 —— 构建速度毫秒级，几百篇文章也是秒出
  • 简单 —— 单个二进制文件，不用装一堆依赖
  • Markdown —— 写作体验纯粹，专注内容本身

评论用了 Giscus，基于 GitHub Discussions，不用担心数据归属和隐私问题。搜索用的是 Fuse.js，前端模糊搜索，对于个人博客的规模足够了。

计划写些什么

  • 技术踩坑记录
  • 工具和效率分享
  • 偶尔的随笔和读书笔记
